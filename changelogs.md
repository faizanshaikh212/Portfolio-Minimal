# Changelog

Notable changes to the portfolio are documented here. Versions follow

- Add initial profile, skills, and selected project content from the CyberSpace portfolio reference.

- Align the light theme to blue glass surfaces and the dark theme to the toggle's deep navy night sky.
- Move the reusable theme toggle into `src/components/` and remove the old root reference folder.
- Add smooth color transitions between themes and coordinate project artwork with the blue palettes.
